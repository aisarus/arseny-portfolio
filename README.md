# Arseniy Perel — AI Product Builder Portfolio

Interactive portfolio for **Arseniy Perel**, focused on AI-native product building, automation and rapid prototyping.

The site is built around one idea: turning ambiguous goals into systems that can be challenged, inspected and verified. The interaction language moves from signal noise to clarity, with each case study exposing a different part of that process.

## Featured work

- **[Aegis Operator](https://github.com/aisarus/aegis-operator)** — autonomous AI-development operator built around acceptance contracts, capability-based routing, evidence and replanning.
- **[Lamdan](https://github.com/aisarus/syllabus-to-os)** — source-linked academic workspace for reviewable AI-generated study material.
- **[BotForge](https://github.com/aisarus/ai-employee-forge)** — Telegram / Supabase automation prototype with explicit security-hardening notes.
- **Lab** — TWIN, Djbrain, TRI·TFM experiments and a WhatsApp receptionist architecture prototype.

## Routes

- `/` — interactive portfolio.
- `/cv` — print-friendly / ATS-friendly CV.

The homepage includes an **FX On / Off** control. Reduced-motion preferences are respected, and the core content remains readable without the decorative signal/glitch layer.

## Stack

React 19 · TypeScript · TanStack Start / Router · Vite · Tailwind CSS · DOM / SVG / CSS motion.

## Development

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

## Positioning

A substantial amount of implementation work across these projects is AI-assisted. The portfolio is intentionally explicit about that. The focus is product definition, system boundaries, decomposition, agent direction, review, failure diagnosis, verification and iteration — not pretending every line was typed manually.
