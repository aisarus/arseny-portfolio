# Arseniy Perel — AI Product Builder Portfolio

**Live site:** [arseny-portfolio-aisarus-projects-37ae3e37.vercel.app](https://arseny-portfolio-aisarus-projects-37ae3e37.vercel.app)

Interactive portfolio for **Arseniy Perel**, an AI-native Product Builder focused on AI automation, rapid prototyping, system design, debugging and evidence-driven delivery.

The core idea behind the site is simple:

> **I turn ambiguous ideas into verifiable products.**

The portfolio is intentionally interactive. Its visual language moves from signal noise toward clarity, mirroring the working process behind the projects: define the target, decompose the problem, build, break, diagnose, verify and ship.

## Live work

### [Aegis Operator](https://github.com/aisarus/aegis-operator)
A local autonomous development operator built around acceptance contracts, capability-based worker routing, evidence, rejection/replanning and owner control.

### [Lamdan](https://github.com/aisarus/syllabus-to-os)
An AI-first academic workspace for source-linked study material, reviewable generated content and reliability-oriented local workflows.

### [BotForge](https://github.com/aisarus/ai-employee-forge)
A Telegram automation / SaaS prototype using React/TypeScript, Supabase, Edge Functions and real integration paths, including documented security hardening.

### Lab
- [TWIN](https://github.com/aisarus/Twin) — deterministic CSS/SVG motion timeline.
- [Djbrain](https://github.com/aisarus/Djbrain) — interactive Three.js procedural visualization.
- TRI·TFM — ongoing proposer / critic / verifier and prompt-optimization experiments.
- WhatsApp Receptionist — prototype architecture for QR-linked sessions, inbound handling, AI/autoresponder decisions and outbound replies.

## About the implementation

Most implementation work is AI-assisted. The portfolio does not present that as manual line-by-line software engineering. The work shown here focuses on product definition, architecture and constraints, decomposition, agent steering, review, failure diagnosis, verification and iteration.

## Stack

React 19 · TypeScript · TanStack Start / Router · Vite · Tailwind CSS · custom DOM/SVG/canvas interactions.

The interactive site includes a user-controlled **FX On / Off** mode and respects reduced-motion preferences. First paint is static and touch/compact devices default to FX off unless the visitor explicitly enables it.
